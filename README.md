Fuente: API `/api/bot/applications/` · Fecha de revisión: 22/10/2026.

## Observaciones a corregir

| Trámite | Observación |
|---|---|
| [Registrarte como titular o adscripto](https://stg.webcorrientes.com/registrartecomotitularoadscripto) | La suma no cierra: dice $192.530 = $189.160 + $3.950, pero eso da **$193.110**. |

| [Presenta la asamblea que aprueba estados contables](https://stg.webcorrientes.com/validaelbalanceanualdetusociedad) | Indica actuación de **$8.120**; otras fichas IGPJ (directorio, gerente, reserva de nombre) indican **$8.410**. |
| [Pasaporte para menores de edad](https://stg.webcorrientes.com/Pasaporteparamenoresdeedad) | El título "¿Tiene costo?" aparece **duplicado**. |
| [Trasladá el domicilio social a Corrientes](https://stg.webcorrientes.com/trasladaeldomiciliosocialaCorrientes) | Existe una ficha **duplicada** (id 306): [traslada-el-domicilio-social-a-Corrientes](https://stg.webcorrientes.com/traslada-el-domicilio-social-a-Corrientes). |
| Trámites de Seguridad Vial / Observatorio | Responden "No" pero aclaran "no detalla/no especifica costos": conviene confirmar si son gratuitos. |
| Unión convivencial · Actualización DNI 5 a 8 años | Dicen que tiene costo pero **no informan monto**. |
| Varios IGPJ | Indican "tasa vigente / tasa de actuación" sin monto, mientras otras fichas del mismo organismo sí lo informan. |
